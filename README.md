🎓 AI Quiz Generator

An AI-powered educational quiz generation application built using Python, Streamlit, Ollama, and Llama 3.2.

📌 Project Overview

AI Quiz Generator helps students practice their knowledge by generating educational multiple-choice quizzes based on their selected subject, topic, and difficulty level.

✨ Features
Generate educational quizzes automatically.
Select different academic subjects.
Choose quiz difficulty: Easy, Medium, and Hard.
Generate 5–20 questions.
Interactive multiple-choice questions.
Automatic quiz evaluation and scoring.
Display correct answers and explanations.
Runs locally using Ollama and Llama 3.2.
🛠️ Technologies Used
Python
Streamlit
Ollama
Llama 3.2
⚙️ Installation
1. Clone the repository
bash
git clone https://github.com/YOUR-USERNAME/AI-Quiz-Generator.git

2. Navigate to the project
bash
cd AI-Quiz-Generator

3. Install dependencies
bash
pip install -r requirements.txt

4. Install and run Ollama

Download Ollama from https://ollama.com/

Pull the model:

bash
ollama pull llama3.2

5. Run the application
bash
streamlit run app.py
